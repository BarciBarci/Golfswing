🎬 Video: After loading, the video can be trimmed – the start and the end are cut off. Then you play it in slow motion, draw lines and circles on it and save everything as a .glf project. The trimmed video can also be saved separately as a video file (“💾 Save as file”).

📦 .glf: A .glf file contains the video data together with all lines and circles (plus the trim and settings). If a trim is set, the file contains exactly the trimmed video; without a trim, the full video is embedded. Reopen it anytime to continue your analysis exactly where you left off.
